# 祝丹妮作品集

个人作品集网站，包含视频、文案与播音作品。

## 修改内容

在 GitHub 仓库打开 `index.html`，点击编辑按钮修改介绍、作品说明和链接，然后提交更改。排版样式位于 `style.css`，交互功能位于 `app.js`。作品文件存放在 `assets/`。

替换作品文件时保持原文件名，即可沿用网页中的现有链接。页面中的文案正文与下载原稿是分别保存的，修改原稿后也应同步修改 `index.html` 中的对应正文。

GitHub Pages 启用后，提交到 main 分支的更改将自动发布。此版本为静态网站，不包含在线登录管理后台。
